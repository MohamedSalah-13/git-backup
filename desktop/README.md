# Git Backup Desktop (نسخة JavaFX)

برنامج سطح مكتب يقوم بما تقوم به سكريبتات PowerShell في جذر المستودع، لكن دون حاجة إلى تثبيت Git:
يعرض مستودعات حسابك على GitHub، تختار منها، ثم ينسخ المختار إلى ملفات ZIP (ملفات الفرع الرئيسي + التاريخ الكامل).

هذه نسخة أولى (0.1) للتجربة والتطوير، وليست جاهزة للتوزيع على العملاء بعد.

## المتطلبات

- JDK 25 أو أحدث
- Maven 3.9 أو أحدث

## التشغيل

```powershell
mvn package
java -jar target\git-backup-desktop.jar
```

أو أثناء التطوير:

```powershell
mvn javafx:run
```

النسخ بدون نافذة (للجدولة لاحقًا)، وينسخ الاختيار المحفوظ:

```powershell
java -jar target\git-backup-desktop.jar --backup
java -jar target\git-backup-desktop.jar --backup --force
```

رمز الخروج: 0 نجاح، 1 فشل بعض المستودعات، 2 تعذّر البدء.

## المثبّت

```powershell
.\packaging\build-installer.ps1
```

ينتج `target\installer\Git Backup-<الإصدار>.exe` (نحو 47MB). البرنامج المثبّت يحمل Java معه، فلا يحتاج العميل إلى Java ولا Git.
التثبيت لكل مستخدم (بدون صلاحيات مدير)، مع اختصار في قائمة ابدأ وعلى سطح المكتب، والإصدار الأحدث يستبدل الأقدم.

- يحتاج البناء إلى WiX Toolset 3.x. بدونه: `-Type app-image` ينتج مجلدًا يعمل مباشرة دون مثبّت.
- المثبّت غير موقّع رقميًا، فسيعرض Windows تحذير "ناشر غير معروف" عند العميل إلى أن تُشترى شهادة توقيع.
- لتغيير الأيقونة: عدّل `packaging\MakeIcon.java` ثم `java packaging\MakeIcon.java .`

## الأيقونة بجوار الساعة والنسخ التلقائي

- إغلاق النافذة لا يغلق البرنامج: يبقى بجوار الساعة. القائمة هناك: فتح، نسخ الآن، خروج.
- تشغيل البرنامج مرة ثانية يُظهر نافذة النسخة العاملة بدل فتح نسخة جديدة.
- **نسخ تلقائي يوميًا الساعة ...**: ينسخ الاختيار المحفوظ مرة في اليوم ما دام البرنامج يعمل. إن فات الموعد والبرنامج مغلق، يُنفَّذ عند فتحه في نفس اليوم.
  يبدأ الفحص بعد 90 ثانية من التشغيل ليُتاح لـ Google Drive أن يعمل، وإن تعذّر البدء يعيد المحاولة كل 10 دقائق. عند الفشل يظهر تنبيه بجوار الساعة.
- **التشغيل مع Windows** (في النسخة المثبّتة فقط): يبدأ البرنامج مخفيًا بجوار الساعة عند تسجيل الدخول. يُكتب في مفتاح `Run` للمستخدم الحالي؛ أزل العلامة قبل إلغاء تثبيت البرنامج.

إن فعّلت النسخ التلقائي هنا فألغِ المهمة المجدولة لسكريبت PowerShell (`install-schedule.ps1 -Remove`) حتى لا يعمل الاثنان على نفس المجلد.

## تسجيل الدخول

- إن كان GitHub CLI مثبتًا ومسجّل الدخول (`gh auth login`) يستخدمه البرنامج تلقائيًا.
- أو من زر "تسجيل الدخول": الصق رمز وصول شخصي (Personal Access Token) بصلاحية `repo`.
  يُحفظ مشفّرًا بـ Windows DPAPI، فلا يقرؤه إلا نفس مستخدم Windows على نفس الجهاز.

## الاستعادة

زر "استعادة..." يعرض كل المستودعات التي لها نسخ في مجلد الحفظ (حتى المحذوفة من GitHub)، ثم تختار النسخة والمجلد:

- **المستودع كاملًا:** نسخة عمل عادية بكل الـ commits والفروع والـ tags، و`origin` يشير إلى عنوانه على GitHub.
- **الملفات فقط:** ملفات الفرع الرئيسي بدون تاريخ.

يُنشأ مجلد جديد باسم المستودع داخل المجلد المختار، وإن كان موجودًا وفيه ملفات تُرفض الاستعادة ولا يُستبدل شيء.
الاستعادة تعمل من ملفات ZIP وحدها، فلا تحتاج اتصالًا بـ GitHub ولا تسجيل دخول. رفع المستودع المستعاد إلى GitHub يتم يدويًا (`git push`).

## التشفير

خانة "تشفير النسخ" تحمي ملفات ZIP الجديدة بكلمة سر (AES-256 بصيغة ZIP القياسية)، فتُفتح أيضًا ببرامج مثل 7-Zip و WinRAR بنفس كلمة السر.

- كلمة السر تُحفظ على الجهاز مشفّرة بـ Windows DPAPI ليعمل النسخ دون سؤال. هذه نسخة للراحة فقط: **إن نسيت كلمة السر وضاع الجهاز فلا يمكن فتح النسخ.** احتفظ بها في مكان آمن.
- المحتوى مشفّر، لكن **أسماء الملفات داخل ZIP تبقى ظاهرة**.
- عند تفعيل التشفير يُعاد نسخ كل مستودع مرة واحدة حتى لو لم يتغير. النسخ الأقدم غير المشفرة تبقى إلى أن تخرج من عدد النسخ المحفوظة، أو احذفها يدويًا.
- تغيير كلمة السر يسري على النسخ الجديدة فقط. عند استعادة نسخة أقدم يطلب البرنامج كلمة سرّها.
- إن كان التشفير مفعّلًا ولا توجد كلمة سر محفوظة يتوقف النسخ بخطأ، ولا يكتب ملفات غير مشفرة.
- سكريبتات PowerShell لا تشفّر. لا توجّهها إلى مجلد حفظ تريده مشفّرًا.

## التوافق مع نسخة PowerShell

النسختان تكتبان نفس `backup-state.json` ونفس أسماء ملفات ZIP وبنفس حساب "البصمة"،
فإن وجّهت البرنامج إلى نفس مجلد الحفظ يكمل من حيث توقفت السكريبتات دون إعادة نسخ.

لا تشغّل النسختين على نفس مجلد الحفظ في الوقت نفسه.

## أين يحفظ البرنامج ملفاته

`%LOCALAPPDATA%\GitBackupDesktop`: الإعدادات (`config.json`)، الرمز المشفّر، نسخ محلية للمستودعات (`mirrors`) لتسريع التحديثات، والسجلات (`logs`).
يمكن تغيير المكان بمتغير البيئة `GITBACKUP_HOME`.

## بنية الكود

| الحزمة | المحتوى |
|---|---|
| `com.gitbackup.backup` | محرك النسخ (JGit) وطبقة الخدمة |
| `com.gitbackup.github` | الاتصال بـ GitHub API وتخزين الرمز |
| `com.gitbackup.store` | قراءة وكتابة الإعدادات وملف الحالة |
| `com.gitbackup.ui` | نافذة JavaFX (عربي / إنجليزي)، سمة AtlantaFX فاتحة/داكنة، أيقونات Ikonli، ونافذة الإعدادات |

## ما لم يُنفَّذ بعد

- إعادة رفع المستودع المستعاد إلى GitHub من داخل البرنامج.
- توقيع المثبّت رقميًا، والتحديث التلقائي.
- تسجيل الدخول عبر المتصفح (OAuth) بدل الرمز.
- المنظمات، و GitLab / Bitbucket.
- Issues و Pull Requests و Wiki و Releases و Git LFS.
- نظام التراخيص.

## للمطوّر

`-Dgitbackup.screenshot=file.png` يحفظ صورة للنافذة بعد تحميل القائمة ثم يخرج، ومع `-Dgitbackup.autorun=true` ينفّذ النسخ أولًا. يُستخدمان للفحص الآلي فقط.
