تحديث لـ **Git Backup** يجلب قوائمك (Lists) من GitHub ويعرضها في البرنامج كما هي.

## التثبيت

- إذا كان عندك الإصدار 0.2.0 أو أحدث، سيعرض عليك البرنامج هذا التحديث بنفسه بعد التشغيل.
- من إصدار أقدم: حمّل `GitBackup-0.3.1-setup.exe` من الأسفل وشغّله. يُحدَّث البرنامج في مكانه وتبقى إعداداتك.
- المثبّت غير موقّع رقميًا بعد، لذلك قد يظهر تحذير SmartScreen. اضغط "More info" ثم "Run anyway".

## الجديد

### قوائمك من GitHub داخل البرنامج

- تظهر قوائم النجوم (Lists) من حسابك على GitHub فوق الجدول بنفس أسمائها وترتيبها، وبجانب كل قائمة أيقونة GitHub وعدد مستودعاتها.
- تأتي قوائم GitHub أولًا، وبعدها القوائم التي تنشئها داخل البرنامج.
- تُحدَّث القوائم مع كل **تحديث للقائمة** ومع كل فحص تلقائي للتحديثات، فأي تغيير تعمله على GitHub يظهر في البرنامج وحده.
- تعديل قوائم GitHub يتم من GitHub نفسه. انقر بالزر الأيمن على اسم القائمة واختر **فتح على GitHub** أو **تحديث من GitHub**.
- يمكنك إيقاف هذه الميزة من **الإعدادات ← الحسابات ← القوائم من GitHub**. عند إيقافها تختفي قوائم GitHub وتبقى قوائمك الخاصة.
- إذا كان عندك في البرنامج قائمة بنفس اسم قائمة على GitHub، لا تُحذف قائمتك، بل يتغير اسمها إلى مثل «العمل (2)».

## ملاحظات

- قوائم GitHub قد تحتوي مستودعات لأشخاص آخرين وضعت عليها نجمة. هذه لا تظهر في الجدول ولا تدخل في العدد بجانب اسم القائمة.
- إذا كنت سجّلت الدخول من داخل البرنامج (عبر المتصفح) في إصدار سابق ولم تظهر قوائمك، سجّل الدخول من جديد، لأن قراءة القوائم الخاصة تحتاج صلاحية إضافية. مستودعاتك تبقى ظاهرة في كل الأحوال.
